# Poetry Python 3.11

> [!IMPORTANT]
>
> The `poetry-python3.11` image is deprecated and will be deleted. Move to a
> maintained Python toolchain chosen by your Python team.
> [uv](https://docs.astral.sh/uv/) is one option. See
> [#4456](https://github.com/coopnorge/engineering-docker-images/issues/4456).

Base image for Python 3.11 and the latest available version of Poetry. This
image is intended to use for projects with Python 3.9 and Poetry.
